# URL 导航

一个 hao123 式的链接聚合页，但刻意做得简单：**一个分类，下面挂链接，两层到底**。

## Language

**分类（Category）**：
第一层，也是唯一的一层分组。**不做嵌套** —— 嵌套一旦开口，整理链接就会变成
一件需要动脑的事，而这个页面的全部价值在于"打开就点"。
_Avoid_: 目录、文件夹 —— 这两个词自带"可以套娃"的暗示。

**常用区**：
展示页顶部按 `clickCount` 取的 Top 8，不是一个分类，也不能手动编辑。
_Avoid_: 置顶、收藏 —— 那会让人以为可以手动往里放。

**重置统计**：
把所有链接的 `clickCount` 清零。它是「累加计数不衰减」这个取舍的配套出口，
不是"清空数据"。
_Avoid_: 清空、清除记录。

**首字母色块**：
`icon` 为空时的默认图标：域名首字母 + 按域名哈希出的固定底色。
它是**默认值**，不是"没有图标"。
_Avoid_: 占位图、默认图标。

## 两个已知取舍

**累加计数不衰减。** 三个月前集中用过的链接会一直霸占常用区。
放弃的替代方案：点击事件表（准确、能长出使用报告，代价是一张只增不减的表加清理策略）、
时间衰减评分（一个字段解决衰减，代价是排序结果没法解释）。
**出口是手动「重置统计」按钮** —— 个人工具，重心变了自己点一下就行。

**越权校验必须逐处手写。** 链接不直接带 `userId`（它挂在分类下），
凡是按 `linkId` 操作都要经分类回溯校验归属。少写一次就是一个越权读写接口，
**而且不会有任何报错提醒你**。`nav.e2e.spec.ts` 里有一组 9 条的越权用例专门盯着。
