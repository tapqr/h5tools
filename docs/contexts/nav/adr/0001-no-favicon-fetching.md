# 不做 favicon 抓取，默认用首字母色块

`icon` 字段为空时，前端渲染「域名首字母 + 按域名哈希出的固定底色」。
想要真图标就手动往 `icon` 里填一个 URL 或 emoji。

## 为什么

**决定性的理由是内网地址。** 这是个人效率工具，收录的链接里相当一部分是
`http://jenkins:8080`、`http://wiki/page/1` 这类内网地址 —— 而所有第三方
favicon 服务（Google s2、DuckDuckGo icons 之流）对内网域名一律抓不到。
**越是这个导航页最该收录的链接，自动抓取越指望不上。**

次要理由两条：链接量级是几十条，手动填一次的总成本低于写一套「抓取 + 缓存 +
失败兜底 + 定期刷新」；真抓来的 favicon 尺寸、清晰度、背景色参差不齐，
混在一起反而比统一色块难看。

## 代价

导航页第一眼是一片字母方块，没有 hao123 那种五颜六色的品牌辨识度。

## 升级路径是通的

以后真想要自动抓取，加一个「自动获取图标」按钮，把抓到的地址写进**同一个
`icon` 字段**即可，数据模型不用动。
